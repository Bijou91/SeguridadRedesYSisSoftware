# st3g0

## Descripción
Download this image and find the flag.
- [Download image](https://artifacts.picoctf.net/c/217/pico.flag.png)
## Solución
Para este reto lo único que haremos es aplicarle un zsteg al archivo para encontrar algún dato oculto, añadiendo un grep para que solo nos muestre lo que realmente nos interesa
```
┌──(kali㉿kali)-[/media/sf_almacenamientoCompartido/T04_Forensic/st3g0]
└─$ zsteg -a -v pico.flag.png | grep "picoCTF{"
b1,rgb,lsb,xy       .. text: "picoCTF{7h3r3_15_n0_5p00n_a9a181eb}$t3g0"
    00000000: 70 69 63 6f 43 54 46 7b  37 68 33 72 33 5f 31 35  |picoCTF{7h3r3_15|
```
