# 2Warm

## Descripción
Can you convert the number 42 (base 10) to binary (base 2)?

## Solución
### Solución 1:
- Usando RapidTables:
https://www.rapidtables.com/convert/number/decimal-to-binary.html?x=42

### Solución 2:
- Usando Python
```python
>>> bin(42)
'0b101010'
```
