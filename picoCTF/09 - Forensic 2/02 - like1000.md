# like1000

## Descripción
This [.tar file](https://challenge-files.picoctf.net/c_fickle_tempest/cd3d027215d8cfee8a81a7700f7b6d2f4bd33d5f481c4464e3766055408fc935/1000.tar) got tarred a lot.
## Solución
Este archivo tar se ha comprimido una y otra vez hasta llegar a las 1000 compresiones, para eso usaremos este script en python, que descomprimirá todo de forma automática
```
┌──(kali㉿kali)-[/media/sf_almacenamientoCompartido/14_Forensic2/1000]
└─$ for i in {1000..1}; do tar -xvf $i.tar; done
```
