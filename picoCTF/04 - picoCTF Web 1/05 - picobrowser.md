# picobrowser

## Descripción
This website can be rendered only by picobrowser, go and catch the flag!
## Solución
### Solución:
Al abrir la página web, vemos que hay un botón que nos entrega la flag
![[05picobrowser01.png]]

pero, como nos indicaba la descripción del reto, solo picobrowser puede acceder, y yo que soy Brave recibo este mensaje
![[05picobrowser02.png]]

Como describía el reto, debemos ser picobrowser para poder entrar, pero en lugar de descargar un navegador nuevo, editaremos nuestro User Agent a 'picobrowser' para poder saltarnos esa medida de seguridad
![[05picobrowser03.png]]

Después de editar y reintentar tomar la flag, al ahora ser de picobrowser, podemos entrar
![[05picobrowser04.png]]
